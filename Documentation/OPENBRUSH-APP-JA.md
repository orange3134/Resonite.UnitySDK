# Open Brush → Resonite アプリ

SDKフォルダーの **OpenBrush Importer.exe** をダブルクリックして起動します。

1. **選択…** からOpen Brushで書き出したGLBを選びます。
2. 対象ワールドのResoniteLinkに表示されている**ポート番号**を入力します。
3. **書き順アニメーション**を「なし」または「あり」にします。
4. **読み込み**を押します。

「なし」は完成形を読み込みます。Starsなど、ブラシ固有の効果は残ります。「あり」は書き順の再生を含めて読み込みます。元データの縮尺を保ち、ワールド原点からZ方向に2mずらして配置します。GLB自体の座標によっては離れた場所や大きなサイズで出現することがあります。

## 進捗と結果

画面は **変換 → 準備 → 送信** と進みます。件数が分かる処理では実際の処理済み件数と割合を表示します。件数が分からない処理ではバーが動きます。割合は現在の工程の進捗であり、全工程の所要時間を推定したものではありません。

「読み込み完了」はUnityの終了コードと、その実行で新しく生成されたSDKレポートの両方で判定します。Resonite内ですべての画像が描画できたことまで保証する表示ではありません。大きな作品は転送に時間がかかります。

失敗したときは画面のエラーを確認し、**ログ**を開いてください。解像度を調整したブラシがある場合も完了画面に表示し、ログの「結果」に詳細を残します。再実行は別名のモデルと別の出力フォルダーを作るため、以前の結果を上書きしません。

**中止**はこのアプリが起動した処理だけを終了します。送信が始まっている場合、ワールドに途中までのモデルが残ることがあります。閉じるボタンも処理中は中止の確認になり、中止後にもう一度閉じられます。

## 初回設定

既存のカスタムSDK、Unity 2022.3.62f3、`.venv-openbrush` を使います。追加のGUI用ライブラリは必要ありません。このexeはSDK内のPythonアプリを起動するランチャーです。exe単体を別の場所へ移動せず、SDKフォルダーと一緒に使用してください。

右上の**設定**で次を変更できます。

| 項目 | 指定するもの |
| --- | --- |
| Unity.exe | SDKに対応するUnity Editorの実行ファイル |
| ブラシ素材フォルダー | Open Brushの `Support/shaders/brushes` フォルダー |

ファイル、ポート、アニメーション設定は次回起動時も引き継ぎます。このSDKをUnity Editorで開いている場合は、閉じてから実行してください。アプリ同士の同時送信は排他制御します。

入力GLBに必要なデータ、対応ブラシ、SDK環境のセットアップは[従来の手順書](OPENBRUSH-IMPORT-JA.md)と[ブラシ対応表](OPENBRUSH-BRUSH-SUPPORT-JA.md)を参照してください。アプリでも同じ変換処理と制約を使います。

## 保存先

- 変換結果：SDKの親フォルダー内 `OpenBrushImports/<作品名>-<モード>-<日時>-<ID>/`
- 実行ログとレポート：SDK内 `.local/importer/runs/<日時>-<ID>/`
- 前回の設定：SDK内 `.local/importer/settings.json`

ログ画面の**フォルダーを開く**から、今回の実行ログに移動できます。

## 開発時の確認

```powershell
& .venv-openbrush/Scripts/python.exe -m unittest discover -s Support/ImporterApp -p 'test_*.py'
& .venv-openbrush/Scripts/python.exe -m unittest discover -s Support/Python -p 'test_*.py'
& ./Support/ImporterApp/build.ps1
```

`build.ps1` はWindows標準の.NET Framework C#コンパイラーを使って起動用exeを再生成します。Pythonの変更だけならexeの再生成は不要です。
